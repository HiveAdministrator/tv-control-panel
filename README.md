# TV Control Panel

Бесплатная панель для управления Android TV через ADB: добавляйте телевизоры, отправляйте команды пульта, находите уже сопряжённые устройства в локальной сети и открывайте трансляцию экрана через scrcpy.

> **Важно:** приложение не выполняет первоначальное ADB-сопряжение за вас. Сопрягите компьютер с телевизором один раз через `adb pair`, а затем панель сможет подключаться к уже сопряжённому устройству.

## Возможности

- Несколько телевизоров в одном окне.
- Поиск доступных ADB-устройств по mDNS.
- Кнопки Home, назад, навигация, OK, громкость, сон и пробуждение.
- Просмотр экрана телевизора в окне или во весь экран через scrcpy.
- Сохранение списка телевизоров в профиле Windows.
- Прокрутка списка мышью или колёсиком.

## Требования

- Windows 10 или Windows 11.
- Телевизор с Android TV / Google TV и компьютер в одной локальной сети.
- Включённая на телевизоре **Беспроводная отладка**.
- Для просмотра изображения с ТВ — установленный [scrcpy](https://github.com/Genymobile/scrcpy), доступный через `PATH`.

Готовый EXE включает ADB. Для запуска приложения из исходников необходимы Android Platform Tools: положите их в `android-platform-tools/platform-tools/` или добавьте `adb` в `PATH`.

## Подключение телевизора

### 1. Включите режим разработчика

Названия разделов немного различаются у разных производителей:

1. Откройте настройки телевизора → **Система** (или **Настройки устройства**) → **Об устройстве**.
2. Найдите пункт **Номер сборки** и несколько раз нажмите OK, пока телевизор не сообщит, что режим разработчика включён.
3. Вернитесь в настройки и откройте **Для разработчиков**.
4. Включите **Беспроводную отладку**.

### 2. Сопрягите компьютер и телевизор

На ТВ откройте **Беспроводная отладка** → **Сопряжение устройства с кодом**. На экране появятся временный код и адрес с портом сопряжения.

Откройте PowerShell в папке Android Platform Tools и выполните:

```powershell
.\adb.exe pair <IP-АДРЕС-ТВ>:<ПОРТ-СОПРЯЖЕНИЯ>
```

Введите код, показанный на телевизоре. Например, адрес сопряжения выглядит как `192.168.1.50:37123`; это только пример.

**Порт сопряжения и порт подключения могут отличаться.** Не используйте порт сопряжения для постоянного подключения.

### 3. Добавьте ТВ в панель

1. Запустите `TV-Control-Panel.exe`.
2. Нажмите **Найти по ADB** — панель добавит устройства, которые ADB обнаружил в сети, или нажмите **Добавить ТВ** и заполните имя и ADB-адрес вручную.
3. Нажмите **Подключить** на карточке телевизора.
4. Используйте кнопки пульта. Для изображения нажмите **Просмотр** или **Полный экран**.
5. Нажмите **Сохранить**, чтобы запомнить список.

Если добавляете вручную, укажите текущие IP-адрес и **порт беспроводной отладки/подключения**, показанные в настройках ТВ. Они могут измениться после перезапуска телевизора или роутера. Кнопка **Найти по ADB** удобнее для уже сопряжённых устройств.

### Просмотр через scrcpy

Установите scrcpy с официальной страницы проекта и убедитесь, что команда `scrcpy` доступна из PowerShell. Если используется только `scrcpy.exe`, добавьте содержащую его папку в системный `PATH`, затем перезапустите панель.

Панель запускает отдельное окно scrcpy для каждого ТВ. Кнопка **Полный экран** передаёт scrcpy параметр полноэкранного режима. Если scrcpy не найден, команды пульта и ADB продолжают работать, но просмотр экрана будет недоступен.

## Настройки и конфиденциальность

Список устройств хранится локально в:

```text
%APPDATA%\TV-Control-Panel\tv-panel.json
```

При первом запуске отображаются две пустые карточки. Введите адреса своих телевизоров или удалите ненужные карточки. Не публикуйте свой `tv-panel.json`: в нём могут быть IP-адреса вашей локальной сети.

ADB предоставляет широкие возможности управления устройством. Используйте беспроводную отладку только в доверенной сети и выключайте её, когда она не нужна. Не подтверждайте сопряжение для незнакомых компьютеров.

## Сборка из исходников

Для сборки нужны Python с Tkinter, PyInstaller и Android Platform Tools.

1. Установите Python для Windows и PyInstaller:

   ```powershell
   py -m pip install pyinstaller
   ```

2. Скачайте Android Platform Tools с [официальной страницы Android](https://developer.android.com/tools/releases/platform-tools) и распакуйте файлы так, чтобы существовали:

   ```text
   android-platform-tools\platform-tools\adb.exe
   android-platform-tools\platform-tools\AdbWinApi.dll
   android-platform-tools\platform-tools\AdbWinUsbApi.dll
   ```

3. Из папки проекта запустите тесты и соберите EXE:

   ```powershell
   py test_tv_panel.py
   py -m PyInstaller --noconfirm TV-Control-Panel.spec
   ```

Готовый файл появится в `dist\TV-Control-Panel.exe`. Для просмотра через scrcpy установите его отдельно — сборка панели его не включает.
